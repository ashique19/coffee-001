# Fancy Coffee menu imagery

Stock photos used for the 10 representative catalog products (`public/images/menu/`).
Licenses: [Unsplash License](https://unsplash.com/license) and [Pexels License](https://www.pexels.com/license/).
Both allow commercial use. These are generic stock photos — not Fancy Coffee’s real cups, staff, or branding.

Each product has a `.webp` file (about 600px wide) and a `.jpg` fallback. Paths stored on `products.image_url` are relative to `public/`, for example `images/menu/espresso.webp`.
